# Intergalactic-Intruders
This is a Space invaders inspired game written in python with Tkinter, all assets I have created and own.

# Running

After downloading the project it can be run with ```python3 main.py```. The project runs on both Linux and Windows.

# Controls

Move left and right with ```left arrow key``` and ```right arrow key```. You can shoot with ```space```.

To toggle pause in the game ```p``` can be pressed. ```ESC``` can be pressed if you are supposed to be working. Buttons can be re-mapped in the included config file found in ```DataFiles/config.txt```.

There are secret cheat codes that can only be discovered in the source code. Scores are marked with a cheated flag if used.
